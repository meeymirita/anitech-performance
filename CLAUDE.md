# anitech-performance — сборный репозиторий лабораторных

Личная учебная программа пользователя: Laravel/PHP-разработчик (~1.5 года), закрывает пробелы в ООП, инфраструктуре, БД и заодно смотрит фронтенд. Общение — на русском.

**Формат методичек (с 02.10.2026):** HTML-«бандл» — текст лежит в сжатом JSON внутри файла (`window.LAB`), обычный grep/sed по нему не работает. Читать и править через `fixes/common/_tools/bundle.py` (`dump` / `grep` / `sub`, из Python — `rewrite`); `prep.py` умеет оба формата.

**Ещё про методички:** `bundle.jsub(path, [(старое, новое, мин_вхождений)], unit='step-N-M')` — замена по строкам внутри JSON (html и плоский `text`), `jre` — то же регулярками, `patch_template` — правка шаблона. Шаблон одинаков у всех лаб: стили `.tip`/`.trap` внесены только в `caddy.html` и `go-start.html` (07.10), у остальных лаб нет — плашки «Ожидаемый результат» могут наезжать. С 11.10 во ВСЕХ лабах есть `pre{max-width:100%;overflow-x:auto}` и шрифт кода `pre,code{font-family:ui-monospace,'SF Mono',Menlo,…}` (скрипт-патч `patch_template`). С 11.10 общий шаблон поддерживает коды сессий (`code`: 5A, 8B…) и блок «Документация» (`links`) во всех лабах (перенесено из Centrifugo). После перевыгрузки методички из дизайн-исходников — `tools/patch-manuals.py` и `tools/restore-symbols.py` (возвращает символы ✅❌☰, которые редизайн 02.10 стирал). Скриншоты headless Chromium — с `--host-resolver-rules="MAP cdnjs.cloudflare.com 0.0.0.0"`, иначе вместо контента заставка.

**Если методичка пришла самодельным HTML (не бандлом)** — так было с Caddy Lab 05.10: шаблон (`<script type="__bundler/manifest">` + `<script type="__bundler/template">`) у всех лаб побайтово одинаков, отличаются только случайные UUID ассетов в манифесте. Если данные в `window.LAB` уже той же формы (`units[]` с `kind: theory/step/ref`, `sessions[].steps[]` — ссылки по ключу, поля `why`/`deep`/`quiz`) — переупаковка тривиальна: взять `.html` любой существующей лабы как есть и `bundle.transform(path, lambda old: новый_текст_window_LAB)` подменяет payload, валидирует JSON сам. Если схема другая — сначала сверить ключи (`sorted(json.keys())`, по `kind` в `units`) и писать недостающее руками.

**Версии-стандарт (решения пользователя 03.10.2026):** PHP 8.4 везде; Node 24 LTS; Redis 8; PostgreSQL 18 везде, включая `postgresql` и `rabbitmq` (том монтируется в `/var/lib/postgresql`, **не** в `/data`); Traefik v3.7; nginx 1.30; kind v0.33 / Kubernetes 1.37; TypeScript 6.0 (`typescript@~6.0`: просто `typescript` на npm теперь 7.x, с ним `vue-tsc` не работает); Vite 7 везде, где его можно закрепить (`vite@^7` + `laravel-vite-plugin@^2` в Inertia; Nuxt и Angular держат Vite внутри себя); Prisma 7 везде (`prisma@7` — на npm latest у `prisma` это 8.0 RC); NestJS 11 (`@nestjs/cli@11`, `@nestjs/graphql@13`: `@latest` создаёт NestJS 12). Исключение по TypeScript: стартер Nest 11 несовместим с TS 6 (`baseUrl` → TS5101), NestJS/GraphQL-лабы остаются на TypeScript из стартера. Основания и результаты прогонов — `fixes/common/site.md`, раздел «Единые версии».

В каждой лабе: методичка HTML (например `php-coffee/php-coffee.html`: с 05.10 у всех лаб она лежит в корне сабмодуля и называется `<ключ>.html`), README со строкой «Статус:», код прохождения пользователя.

**Актуальный статус лаб — строки «Статус:» в корневом `README.md` и README каждой лабы.** Читать их, а не полагаться на память.

## Правила git

1. **Сначала пушить подмодуль, потом родителя.** Если родитель ссылается на коммит подмодуля, которого нет на GitHub, сборка Pages падает на checkout (`not our ref …`). Так было 26.09 с `works`.
2. Перед пушем родителя проверить, что ни один подмодуль не опережает свой origin:
   `git submodule foreach --quiet 'b=$(git rev-list --count @{u}..HEAD 2>/dev/null); [ "${b:-0}" != 0 ] && echo "$name ahead $b"; true'`
3. Порядок коммитов: коммит в подмодуле → отдельный коммит в родителе «Bump <лаба> submodule: …».
4. Коммитить и пушить только по просьбе пользователя. Сообщения коммитов — на английском.
5. Оболочка может стоять внутри подмодуля. Проверять `pwd` перед `cd <папка>`.
6. `git commit` берёт ВЕСЬ индекс, а не только последний `git add`: перед коммитом смотреть `git status`, после — `git show --stat`, чтобы в коммит не попало лишнее (06.10 так в коммит методички попал чужой файл — пришлось пересобирать до пуша). Личные файлы владельца `caddy/docs/*.md` в git не добавлять (они в `.git/modules/caddy/info/exclude`).
7. **Перед `git add <подмодуль>` в родителе сверить локальный HEAD подмодуля с `origin/main`** (`git -C <папка> fetch && git -C <папка> rev-list --count HEAD..origin/main` → 0). `git add <подмодуль>` фиксирует ЛОКАЛЬНЫЙ коммит: если папка отстаёт, указатель откатывается назад, и сайт с бакетом получают старую методичку (17.10 так откатились vue, nestjs, express, nuxt; поймано и исправлено в тот же день). Подмодули, которые сегодня не трогали, в `git add` не включать, если не уверена.
